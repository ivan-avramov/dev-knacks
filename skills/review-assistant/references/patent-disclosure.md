# Our own invention disclosure, reviewed for filing

Typical decisions: file now, rework first, file defensively, publish instead, drop.

## Pass 0: problem map
- What problem does it solve, for whom, and what is the prior state of the art or product behavior?
- State the claimed inventive step in one sentence; if you can't, that is the first finding.
- Is the problem real and significant? Name the pain the authors cite, and whether the disclosure shows it.

## Pass 1: the inventive step
- Novelty and obviousness: strip the label; map the core mechanism to known patterns across domains, not just the product's own. If the core idea is well established, the filing's value must come from specific, non-obvious implementation details: name which could carry it, and whether the disclosure contains them.
- Enablement: look for mechanisms named but not specified ("we compute feature X", not how). Could a skilled practitioner build it from this text?
- Embodiments: check each claimed variant (e.g. AI or agentic) on its own terms; assess each variant's added scope and risk.

## Operational completeness
Probes that usually expose thin disclosures: apply all of SKILL §9, Operational probes (all types).

## The evaluation questions
Disclosure forms usually carry a rubric.
- Before scoring a question, confirm what it measures and which direction is good for us. Detectability: can *we* detect a competitor infringing? Easy detection favors filing.
- Is each answer substantive or filler? "Might become a best practice someday" informs nothing.
- Business-impact answers often assume feasibility the disclosure hasn't shown; say so.
- Do the authors' own answers undercut the filing? E.g. "many workarounds exist" supports an obviousness concern.

## The filing lens
- Offensive needs broad but defensible claims, enforceability, detectability; defensive tolerates narrower or more obvious claims, still needs enablement; defensive publication is cheaper when the goal is only prior art.
- Timing: if competitive movement is likely, file early for a priority date, with a continuation once implementation matures.

## Record notes
Organize: genuine strengths; gaps to close before filing, ranked by leverage; rubric answers to revisit; filing recommendation with conditions.
